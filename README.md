## 快速上手

第一次使用，先配置提交身份：

```shell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global --list          # 验证
```

每天最常用的三条：

```shell
git pull                            # 开发前先拉
git add . && git commit -m "说明"    # 提交
git push                            # 推送
```

> 一句话总结：**推之前先拉，冲突手动解，解完再推。**

大文件（视频、设计稿、数据集等）交给 LFS，避免把仓库撑爆：

```shell
git lfs install                     # 装一次
git lfs track "*.psd"               # 加追踪规则
git add .gitattributes              # 规则文件必须提交
```
